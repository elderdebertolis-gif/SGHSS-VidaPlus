# Brand Kit VidaPlus

Pacote reconstruído a partir da identidade visual fornecida, preservando as proporções e a silhueta do símbolo, do wordmark e da assinatura visual originais.

## O que usar no projeto
- **Logo principal:** `01_Logos/Vetorial_SVG/vidaplus_logo_horizontal.svg`
- **Logo para cabeçalhos compactos:** `vidaplus_logo_horizontal_sem_assinatura.svg`
- **Símbolo:** `vidaplus_simbolo_colorido.svg`
- **Ícone do app:** `01_Logos/Favicon_App/icon-1024.png`
- **Ícones de interface:** `02_Icones/Vetorial_SVG/`
- **Fundos:** `03_Fundos/`
- **Tokens/CSS:** `04_Design_Tokens/`

## Qualidade
Para interfaces e materiais que podem ser redimensionados, priorize **SVG**. Os PNGs foram renderizados a partir dos SVGs em alta resolução e possuem transparência quando aplicável.

## Tipografia
A identidade de referência indica:
- **Títulos:** Poppins SemiBold
- **Texto:** Inter Regular

As fontes não são incluídas neste pacote. Use as versões oficiais/licenciadas do seu ambiente ou carregue-as pelo provedor de fontes adotado no projeto.
